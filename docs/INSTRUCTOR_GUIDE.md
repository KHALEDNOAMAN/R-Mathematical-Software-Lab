# R Mathematical Software Lab - Instructor Guide

## Overview
Educational GitHub infrastructure for R Programming labs with assignment workflows.

## Classroom Workflow
```
Instructor --> Template Repo --> Student Forks --> Pull Requests --> Review
                  |                  |                |
           Assignment Files    Isolated Work    Automated Checks
```

## Setting Up a New Assignment
| Step | Action |
|------|--------|
| 1 | Create assignment folder with template |
| 2 | Add R script skeleton + instructions |
| 3 | Push to main branch |
| 4 | Students fork and work in their branch |
| 5 | Students submit via pull request |

## Topics Covered
| Week | Topic | R Packages |
|------|-------|-----------|
| 1-2 | R Basics | base, utils |
| 3-4 | Data Manipulation | dplyr, tidyr |
| 5-6 | Visualization | ggplot2 |
| 7-8 | Linear Programming | lpSolve |
| 9-10 | Optimization | optim, nloptr |

## Grading
- Code correctness (40%)
- Documentation (20%)
- Code style (20%)
- Tests (20%)
